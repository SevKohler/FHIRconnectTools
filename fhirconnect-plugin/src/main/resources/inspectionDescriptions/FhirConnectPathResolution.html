Reports FHIRconnect mapping methods whose resolved openehr path is not a node of the operational template / web template associated with the mapping, whose resolved fhir path is not an element of the FHIR profile (or base R4 resource), and slotArchetype, extends and context references that do not name a known mapping.

Templates and StructureDefinitions are picked up from anywhere in the project (for example a resources/ folder next to the mapping files). A mapping file is associated through the context file in its folder (template id and profile url), or by the archetype it maps.
